# @olenna/tokens

## 2.2.0

### Minor Changes

- Added master color tokens: `color.brand.plum.announcement` (`#6B4B5E`), `color.brand.surface.footer` (`#FAF3F0`), and `color.brand.surface.tint` (`#F6E6ED`).
- Added semantic surface mappings: `surface.footer` and `surface.tint`.

## 2.1.0

### Minor Changes

- Disabled dark mode across all selectors, forcing light mode tokens globally.

## 2.0.0

### Major Changes

- 7047a38: Initial production release of Olenna StudioX Design Language System (DLS) v1.0.0.
  - `@olenna/brand-assets`: Approved vector SVGs, master PNGs, and brand metadata.
  - `@olenna/tokens`: Platform-neutral design token source, CSS custom properties, and typed constants.
  - `@olenna/styles`: CSS stylesheet, accessible resets, and Tailwind preset.
  - `@olenna/react`: Full suite of accessible, theme-aware React components (WCAG 2.2 AA).
  - `@olenna/patterns`: Luxury retail presentation patterns, boutique directories, and PWA banners.
